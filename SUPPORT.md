# Support

## Raising a support ticket

1. Sign in to the DBCH portal at https://dobigcloudhub.ttns.in with the user ID and password that TTNS sent you.
2. Open **Support** in the left menu, then **View Ticket**.
3. Click **+** to raise a new ticket and complete all mandatory fields.
4. Click **Submit** and keep the generated **Ticket ID** for reference.

Managed infrastructure support is provided as defined in the support matrix of your agreement with TTNS.

## Before you raise a ticket

- **A document failed:** open it from **History**. The failure message says why (unsupported file, throttling,
  quota, access). See [the user guide](Documents/user-guide.md#troubleshooting).
- **Sign-in says "not configured":** no demo password has been set for the environment. See the
  [deployment guide](Documents/deployment-guide.md#troubleshooting).
- **Deployment problems:** see the troubleshooting section of the [deployment guide](Documents/deployment-guide.md#troubleshooting).
- **Logs:** web app logs are in the App Service *Log stream* and in Log Analytics (`<prefix>-<env>-<suffix>-log`).

Include the document ID (shown in History and in exports), the environment, the approximate time (with time zone)
and any error text. Do not attach real invoices; reproduce with a sample invoice if you can.
