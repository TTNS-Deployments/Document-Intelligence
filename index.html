Architecture

Browser to API Management to Function app to Document Intelligence, with documents and results kept in Storage.

Set the SKUs in one file

Everything lives in config/skus.env. No template edits.

Document Intelligence

DOCINT_SKU = S0

VPN Gateway

VPN_GATEWAY_SKU = VpnGw1AZ

Functions

FUNCTION_PLAN_SKU = Y1

API Management

APIM_SKU = Consumption

Storage

STORAGE_SKU = Standard_LRS, Hot

Upload limits

MAX_UPLOAD_MB = 20

Deploy

  1. Sign in with az login and pick your subscription.
  2. Review config/skus.env and set APIM_PUBLISHER_EMAIL when prompted or in the environment.
  3. Run ./deploy.sh. The VPN gateway builds in the background, so the upload page is ready sooner than the whole run.
  4. Open the upload page URL printed at the end and paste the API key shown there.
  5. Optional: run ./connect-vpn.sh to link another gateway.

Good to know

  • These templates and scripts were tested with mocks and local checks, not against a live Azure subscription. Try them in a dev subscription first.
  • The VPN tier is deployed as VpnGw1AZ because VpnGw1 without AZ can no longer be created for new gateways.
  • The VPN gateway has nothing private to connect to while Functions, APIM and Storage use public endpoints.
  • The page uses a shared API Management key. Add Microsoft Entra sign-in before real use.
  • The Linux Consumption plan retires on 30 September 2028; plan a move to Flex Consumption.
